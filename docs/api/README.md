# API Documentation

Documentacion de endpoints HTTP del servicio WhatsApp.

## Indice
- webhook.md: verificacion y recepcion de eventos.
- status.md: estado y health checks.
- messages.md: envio de mensajes y plantillas.
- queue.md: control y monitoreo de colas.
- cache.md: cache de numeros.

## Prefijos
- La mayoria de los endpoints usan prefijo `/api`.
- El webhook no usa prefijo y vive en `/webhook`.
